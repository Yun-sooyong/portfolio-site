# 일본 G1 경마 리플레이 뷰어 — AI 작업 흐름

![일본 G1 경마 리플레이 뷰어 AI 작업 흐름](g1-archive-viewer.svg)

[작업 흐름 목록으로](README.md)

## 단계

| 순서 | 행위자 | 내용 |
|---|---|---|
| 1 | 나 | 목표 정하기 (경기 영상 위에 말 위치를 겹쳐 보기, 마권 예측은 하지 않음) |
| 2 | Claude Code | 수집과 복원 (YouTube 재생목록, netkeiba 결과 수집, 단조 보간으로 0.1초 간격 위치 복원) |
| 3 | 검사 | verify로 130경기를 원본 기록과 대조 (착순, 착차, 완주 시각, 단조성) |
| 4 | Claude Code | 화면 작성 (영상, 코스맵, 진행바, 출전표가 같은 시각을 가리키게) |
| 5 | 나 | 화면을 보고 고칠 점 요청 (영상을 코스맵 안쪽으로, 코스맵 모양 고정, 도트 확대) |
| 6 | 검사 | 보안 점검 3번 (nginx 규칙 순서, 리다이렉트 검사, 요청 제한) |

## 되돌아가는 고리

5단계(고칠 점 요청)에서 4단계(화면 작성)로 돌아가는 고리가 있다. 화면을 고친 뒤 다시 보고 다음 고칠 점을 요청한다.

## 덧붙임

근거는 g1-archive-viewer 저장소의 커밋 기록 12개와 README다. 저장소는 비공개다.
