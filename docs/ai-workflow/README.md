# AI 작업 흐름

Claude Code로 만든 개인 프로젝트 3건의 AI 작업 흐름이다.

## 범례

| 표시 | 뜻 |
|---|---|
| 강조색 바탕에 굵은 테두리 상자 | 내가 판단한 단계 |
| 연한 바탕 상자 | AI가 한 단계 |
| 점선 테두리 상자 | 검사 또는 배포 단계 |

상자 위의 작은 꼬리표는 그 단계를 하는 쪽이다. 나, Opus, Sonnet, Haiku, Claude Code, 메인 모델, 검사, 배포가 있다. 점선 화살표는 다음 단계를 뜻한다. 곡선 화살표는 앞 단계로 돌아가는 고리다.

## 망컷방지

![망컷방지 AI 작업 흐름](mangcut-bangji.svg)

장면에 맞는 구도 가이드를 카메라 화면에 띄우고, 찍은 뒤 빈티지 필터를 고르는 iOS 앱이다. 구도 가이드를 0.0~1.0 비율 좌표로 정의하게 했다. 4:3과 16:9에서 같은 데이터로 그린다.

## 개인 작업 관리자

![개인 작업 관리자 AI 작업 흐름](personal-orchestrator.svg)
