# 포트폴리오 사이트 (이 사이트) — AI 작업 흐름

[작업 흐름 목록으로](README.md)

## 단계

| 순서 | 행위자 | 내용 |
|---|---|---|
| 1 | 나 | 참고 사이트와 수정 요청 (번호 목록) |
| 2 | Opus | 분석과 계획, 선택지 질문 |
| 3 | 나 | 결정 (스크롤 방식, 다크 모드, 넣을 내용) |
| 4 | Sonnet | 구현과 테스트 수정 |
| 5 | 검사 | lint · typecheck · Vitest · build |
| 6 | Opus | 헤드리스 Chrome 캡처 검토 (1440 · 900 · 390px, 다크) |
| 7 | 나 | 확인과 승인 |
| 8 | 배포 | 커밋 · push → GitHub Actions CI → Vercel |

## 되돌아가는 고리

7단계(확인과 승인)에서 2단계(분석과 계획)로 돌아가는 고리가 있다. 고칠 점이 있으면 다시 돌아간다.

## 범례

| 표시 | 뜻 |
|---|---|
| 강조색 바탕에 굵은 테두리 상자 | 내가 판단한 단계 |
| 연한 바탕 상자 | AI가 한 단계 |
| 점선 테두리 상자 | 검사 또는 배포 단계 |
