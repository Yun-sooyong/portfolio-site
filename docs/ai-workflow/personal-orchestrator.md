# 개인 작업 관리자 (취업 준비 도우미) — AI 작업 흐름

![개인 작업 관리자 AI 작업 흐름](personal-orchestrator.svg)

[작업 흐름 목록으로](README.md)

## 단계

| 순서 | 행위자 | 내용 |
|---|---|---|
| 1 | 나 | 목표와 제약 (비용, 개인 정보, 복구) |
| 2 | Opus | 명세 11개 작성 · 문서끼리 어긋난 곳 찾기 |
| 3 | 나 | 설계 결정 선택 (결정 기록 14건) |
| 4 | Opus | 단계 계획 M0~M5 |
| 5 | Haiku | 코드 탐색과 내용 추출 |
| 6 | Sonnet | 구현 |
| 7 | 검사 | pytest 1,078개 · 가짜 어댑터로 실패·재시작·승인 시험 |
| 8 | Opus | 결과 검증과 보고 (바뀐 것, 검증 결과, 남은 제한) |
| 9 | 나 | 승인 → 커밋 |

## 되돌아가는 고리

9단계(승인 → 커밋)에서 4단계(단계 계획)로 돌아가는 고리가 있다. 한 단계가 끝나면 다음 단계의 계획을 세운다.

## 덧붙임

안전 장치: API 키 차단 · 하위 에이전트 git 쓰기 금지 · 이력서 원본은 Git 밖

## 범례

| 표시 | 뜻 |
|---|---|

| 연한 바탕 상자 | AI가 한 단계 |
| 점선 테두리 상자 | 검사 또는 배포 단계 |
