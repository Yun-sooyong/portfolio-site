## 단계

| 순서 | 행위자 | 내용 |
|---|---|---|
| 1 | 나 | 목표와 기준 정하기 (초보자가 이 자료만으로 직접 만들 수 있는 수준, Colab 무료 GPU에서 실행) |
| 2 | Claude Code | 레슨 작성 (Markdown 원본, 실습 코드, 코드 읽기 해설, 퀴즈) |
| 3 | 검사 | Colab T4 기준으로 레슨 코드 실행 |
| 4 | Claude Code | build.py로 노트북 26개와 목차 생성, 레슨 간 링크 검사 |
| 5 | 나 | 레슨을 읽고 고칠 점 요청 (코드 해설 보강, 교수 관점 개편, 0부 신설) |
| 6 | 배포 | push → GitHub Pages |

## 되돌아가는 고리

5단계(고칠 점 요청)에서 2단계(레슨 작성)로 돌아가는 고리가 있다. 요청은 작업 규칙 문서(CLAUDE.md)에 먼저 적고, 그 규칙대로 레슨을 다시 쓴다.
